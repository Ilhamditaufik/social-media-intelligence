# Large-Scale Social Media Intelligence Platform

**Capstone DS-03 — Nexvia Technologies**

## Overview

A data science prototype for multilingual social media intelligence,
sentiment analysis, topic discovery, social network analysis,
misinformation classification, and search analytics.

## Core Features

- Reddit and YouTube data collection through authorized APIs
- Multilingual text preprocessing and sentiment analysis
- Topic discovery and trend analysis using BERTopic
- Social network analysis using NetworkX and Neo4j
- Misinformation classification using labeled datasets
- Search analytics using Elasticsearch and Kibana
- Interactive dashboard using Plotly Dash

## Data Sources

- Public multilingual sentiment datasets
- Publicly accessible YouTube API data
- Reddit API data, subject to approved access
- Labeled misinformation datasets
